# Easy Nihongo

히라가나를 막 익힌 초보자가 일본어 문장을 듣고 직접 말하도록 돕는 회화 중심 학습 웹 앱입니다.

## 실행

Node.js 18 이상에서 별도 패키지 설치 없이 실행할 수 있습니다.

```bash
npm run dev
```

브라우저에서 `http://127.0.0.1:4173`을 여세요.

## 포함된 기능

- 오늘의 듣기·말하기·복습 대시보드
- Supabase 학습 기록을 반영하는 실제 주간 달성 캘린더
- 상황별 회화 챕터와 4단계 카페 주문 수업
- 일본어 음성 재생과 지원 브라우저의 음성 인식
- 하루 5·10·20개 단어 학습량 설정 및 저장
- 히라가나·가타카나·혼동 문자 발음 연습
- 힌트와 말하기를 결합한 회화 복습
- 데스크톱 및 모바일 반응형 UI
- 로그인 필수 시작 화면과 이메일 회원가입·세션 유지
- 이름·생년월일 기반 중복 계정 방지
- 이메일 인증 링크 안내·재전송 흐름
- Supabase PostgreSQL 학습 기록 동기화
- RLS를 통한 사용자별 데이터 접근 제한
- 연결이 끊겼을 때 로컬 대기열 저장 후 자동 동기화

음성 재생은 브라우저의 일본어 음성 합성 기능을 사용합니다. 음성 인식 API를 지원하지 않는 브라우저에서는 체험용 피드백으로 동작합니다.

## 데이터베이스

현재 앱은 서울 리전의 Supabase 무료 프로젝트와 연결되어 있습니다. 다음 기록이 로그인 계정별로 저장됩니다.

- 하루 단어 목표
- 단어별 정답·오답 횟수와 다음 복습일
- 챕터 진행 단계와 완료 여부
- 문장 복습 횟수와 다음 복습일
- 날짜별 학습 세션과 말한 문장 수

홈의 주간 목표는 월요일부터 일요일까지 표시되며, 단어 학습·회화 완료·말하기 복습 중 하나라도 기록된 날짜를 학습일로 계산합니다. 같은 날 여러 번 학습해도 주간 달성일은 하루로 집계됩니다.

테이블과 보안 정책은 [`supabase/schema.sql`](./supabase/schema.sql)에 정의되어 있습니다. 브라우저에는 공개용 publishable key만 포함되며, 데이터는 RLS 정책에 따라 로그인한 본인만 읽고 쓸 수 있습니다. 관리자용 secret key는 저장소와 앱에서 사용하지 않습니다.

회원가입할 때 이름과 생년월일을 저장하며, 같은 이름과 생년월일 조합은 다시 가입할 수 없습니다. Supabase 자체 이메일 중복 검사도 함께 적용됩니다. 이 방식은 신분증 기반 본인 인증은 아니므로 동명이인까지 구분해야 하는 공개 서비스로 확장할 때는 휴대전화 또는 별도 본인 인증 수단을 추가해야 합니다.

회원가입 후에는 Supabase가 보낸 이메일의 인증 링크를 누르도록 안내합니다. 인증 링크를 열면 가입이 완료되고 앱으로 돌아와 로그인할 수 있습니다.

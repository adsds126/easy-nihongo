# Easy Nihongo

히라가나를 막 익힌 초보자가 일본어 문장을 듣고 직접 말하도록 돕는 회화 중심 학습 웹 앱입니다.

## 실행

Node.js 18 이상에서 별도 패키지 설치 없이 실행할 수 있습니다.

```bash
npm run dev
```

브라우저에서 `http://127.0.0.1:4173`을 여세요.

## 포함된 기능

- 오늘의 듣기·말하기·복습 대시보드
- 상황별 회화 챕터와 4단계 카페 주문 수업
- 일본어 음성 재생과 지원 브라우저의 음성 인식
- 하루 5·10·20개 단어 학습량 설정 및 저장
- 히라가나·가타카나·혼동 문자 발음 연습
- 힌트와 말하기를 결합한 회화 복습
- 데스크톱 및 모바일 반응형 UI

음성 재생은 브라우저의 일본어 음성 합성 기능을 사용합니다. 음성 인식 API를 지원하지 않는 브라우저에서는 체험용 피드백으로 동작합니다.
